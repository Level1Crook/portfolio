## 🚀 Deployment Quick Commands

### Local Testing

```bash
# Python 3
python -m http.server 8000

# Then visit: http://localhost:8000
```

### GitHub Deployment

```bash
# Initialize and push
git init
git add .
git commit -m "Initial portfolio"
git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
git branch -M main
git push -u origin main

# Then enable Pages in Settings
# Visit: https://YOUR_USERNAME.github.io/portfolio
```

## 📞 Support & Help

### Common Questions

**Q: How do I change colors?**
A: Edit `css/styles.css` → Find `:root` section → Change `--accent-color`

**Q: How do I add my own content?**
A: Edit `index.html` → Find section → Replace text. Keep HTML structure!

**Q: How do I deploy?**
A: Follow QUICK_START.md or README.md deployment section

**Q: How do I make the form send emails?**
A: See README.md → Optional: Enable Contact Form section (use Formspree)

**Q: Why isn't dark mode working?**
A: Press F12, check Console tab for errors. Make sure script.js is loading.
